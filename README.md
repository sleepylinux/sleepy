# Sleepy Linux

Sleepy Linux is a pre-alpha desktop operating system built on NixOS.

See the [approved design](docs/superpowers/specs/2026-08-23-sleepy-desktop-foundation-design.md) and [implementation plan](docs/superpowers/plans/2026-08-23-sleepy-desktop-foundation.md) for the current foundation milestone.
