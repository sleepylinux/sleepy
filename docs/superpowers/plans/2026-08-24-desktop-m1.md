# Sleepy Desktop Milestone 1 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build the first independently testable contracts → state service → desktop → distribution vertical slice across the Sleepy repositories.

**Architecture:** `sleepy-sdk` defines versioned contracts, `sleepy-session` implements durable user state, `sleepy-desktop` renders the first polished shell surface, and the root `sleepy` flake pins and composes them. Components communicate through validated JSON in this milestone; the reserved D-Bus API is implemented in the next transport milestone without changing document shapes.

**Tech Stack:** Nix flakes, Rust 2024 edition, Serde, JSON Schema, Qt 6/QML, Quickshell, Bash contract tests.

**Spec:** `docs/superpowers/specs/2026-08-24-desktop-m1-design.md`

## Global Constraints

- Product name is `Sleepy Linux`; public identifiers use the `sleepy` prefix.
- Git branches use `feat/` or `chore/`; never use a tool/vendor prefix.
- `schemaVersion` and plugin `apiVersion` begin at integer `1`.
- Built-in preset id is exactly `builtin.sleepy` and cannot be mutated.
- User presets are never overwritten by initialization, rebuild, or update.
- User document replacement is validate → sync temporary file → atomic rename → sync parent directory.
- Geometry uses 12 px rhythm, 22 px shell radii, and 16 px inner radii.
- UI copy is English for this release.
- New behavior follows strict test-first red-green-refactor.
- Full Nix verification runs in CI or the Sleepy VM because this workspace has no `nix` executable.
