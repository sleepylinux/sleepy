# Sleepy Desktop Milestone 3 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Deliver the event-driven daily Sleepy desktop defined by the M3 design.

**Architecture:** A strict v2 SDK feeds one modular `sleepy-sessiond`; Quickshell consumes replayable events and never owns system probes or optimistic state. Component PRs are reviewed before the root pins their exact revisions.

**Tech Stack:** Rust 2021, serde/JSON Schema, Unix sockets, D-Bus, Quickshell/QML, Qt 6 RHI, Niri 26.04, NixOS/Home Manager, QEMU.

**Spec:** `docs/superpowers/specs/2026-08-24-desktop-m3-design.md`

## Global Constraints

- Sleepy-owned sources and packages are GPL-3.0-only.
- No shell interpolation, API keys, physical-hardware tests, installer, disk mutation, or destructive session action in tests.
- Preserve M2 XDG files and all pre-seeded M3 user data byte-for-byte across update unless an explicit user action targets that document.
- Every change follows RED, focused GREEN, full component suite, independent review, Critical/Important fixes, and a focused commit.
